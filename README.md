# 🎮 Game Review

A game review website that allows users to explore games, filter them by platform and category, and view detailed information about each game.

## 🔗 Live Demo
https://malakhany-max.github.io/Game_Review/

## 💻 Repository
https://github.com/malakhany-max/Game_Review

## ✨ Features

- Display games from FreeToGame API.
- Search games by title.
- Filter games by category and platform.
- Sort games by different options.
- View detailed game information.
- Add games to favorites using localStorage.
- Responsive design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- FreeToGame API
